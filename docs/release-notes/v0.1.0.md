LocalGallery is a portable Windows app that creates images and video on your own PC. ComfyUI runs underneath, with a simple UI on top that adapts to each model's own controls.

> **Pre-release.** The app was built and tested end to end on Windows CI, but not yet on a real NVIDIA GPU. Generation speed, VRAM behaviour and output quality still need checking on real hardware (see "Check it on your PC" below).

## Install
1. Download `LocalGallery-0.1.0-win64.zip` and unzip it anywhere, including paths with spaces.
2. Run `LocalGallery.exe`. The exe is not code-signed, so Windows SmartScreen may warn you: choose **More info → Run anyway**.
3. On first use, **Settings › Engine** installs ComfyUI, Python and PyTorch into the app's `engines\` folder. This is about 3 GB for NVIDIA GPUs, and the app asks first.
4. In **Models**, pick one marked as fitting your PC and press **Download**. You can also copy your own `.safetensors`/`.gguf` files into `models\`.

**Requirements:** Windows 10/11 x64 with the WebView2 runtime (built into Windows 11). An NVIDIA GPU is recommended; CPU works, slowly.

**Portable:** the folder is the app. To uninstall, delete it. LocalGallery writes nothing to the registry or `%APPDATA%`. While the window is open, Microsoft's WebView2 runtime keeps a few small keys of its own under `HKCU\Software\Microsoft\EdgeWebView`.

## What's inside
- **Simple, Advanced and Ultra levels:** from one prompt box and a Create button up to sampler, weight format, memory policy and raw graph overrides.
- **Each model's own mechanisms:** JSON/structured prompts, bounding boxes and regional prompts on the canvas, inpaint/outpaint masks, reference images, first frame for video, LoRA stacks.
- **Built-in models:** Stable Diffusion/SDXL, Z-Image Turbo, Ideogram 4 (box layouts), FLUX.2 Klein 4B (edit with references), FIBO 2 (JSON captions; pick its model files in the app) and Wan 2.2 14B video.
- **113 official ComfyUI workflows as ready-made tools.** You can also import any ComfyUI workflow and publish it as a tool.
- **Memory planner:** picks the file format and the VRAM/RAM/NVMe split for your hardware, retries out-of-memory jobs with a lighter plan, and warns about shared-GPU-memory spill.

## Verified
On GitHub Actions `windows-latest` (CI run 6 and this release build):
- **Portable folder:** the app runs from a path with spaces and non-ASCII characters and writes nothing outside its folder. The release zip itself passed this check before upload.
- **Desktop window:** it opens, and a second launch hands over to the first window.
- **UI tests:** 8/8 pass.
- **Real engine install through the app (CPU PyTorch):** all built-in operations and all 113 workflow tools pass ComfyUI's own validation, and the full stack runs on the real engine.

## Not yet verified
Real generation speed, VRAM use, image and video quality, and the fp8/NVFP4 paths on an RTX-class GPU.

## Check it on your PC
Close the app, then from its folder run:
```
powershell -ExecutionPolicy Bypass -File tools\smoke.ps1   # engine + first image: time, VRAM, RAM, spill, black-image check
powershell -ExecutionPolicy Bypass -File tools\bench.ps1   # timings for every downloaded model, sizes and policies
```
Results go to `data\bench\`.

The file `LocalGallery-0.1.0-win64.zip.sha256` holds the zip's SHA-256. ComfyUI (GPL-3.0) runs as a separate process and is downloaded on first use; it is not bundled.
